Connect to GitHub

  1. Open GitHub → New fine-grained token.
  2. Name it davidokunfolami.com writer and pick an expiry (90 days is sensible; you'll make a new one after).
  3. Repository access: Only select repositories → Dah-vid/davidokunfolami.com.
  4. Permissions → Repository permissions → Contents: Read and write. Nothing else.
  5. Generate it, copy it, and paste it below. It's stored only in this browser, never on the site.
